# 坦克大战 (Tank Battle)

一款使用 **pygame** 实现的经典坦克大战游戏（灵感源自 Battle City / 红白机坦克大战），
共 **10 关**，难度递增，包含多种地形、敌人类型与道具。

## 玩法

- 保护你的基地（屏幕下方中间的鹰标 🦅）。
- 击溃每一关的所有敌方坦克即可过关，通关 10 关即胜利。
- 你拥有 **3 条命**，每条命 3 点血量；被子弹击中、撞上敌人或被敌人击中基地都会失败。

## 地图元素

| 符号 | 名称 | 说明 |
| :--: | :--: | :-- |
| `#` | 砖墙 | 可被子弹击碎 |
| `-` | 钢墙 | 不可击碎 |
| `~` | 水域 | 坦克不可通行，子弹可越过 |
| `*` | 草丛 | 坦克可藏身其中（绘制在半透明层之上） |
| `/` | 冰面 | 坦克在上面会打滑 |

## 敌人类型

| 类型 | 速度 | 血量 | 击杀得分 | 颜色 |
| :--: | :--: | :--: | :--: | :--: |
| 普通 (normal) | 1 | 1 | 100 | 银色 |
| 快速 (fast) | 2 | 1 | 200 | 红色 |
| 重火力 (power) | 1 | 2 | 300 | 橙色 |
| 装甲 (armor) | 1 | 3 | 400 | 紫色 |

## 道具 (Power-ups)

击毁敌人有几率掉落道具，坦克碰到即拾取：

| 道具 | 效果 |
| :--: | :-- |
| 🩹 回血 | 恢复 1 点血量 |
| 🛡 护盾 | 8 秒无敌 |
| ⚡ 连发 | 12 秒快速射击 |
| 💣 炸弹 | 消灭场上所有敌人 |
| ⭐ 升级 | 永久提升血量上限与速度 |

## 操作

| 按键 | 功能 |
| :--- | :--- |
| 方向键 / `WASD` | 移动坦克 |
| `空格` / `J` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `Enter` | 开局 / 重新开始 / 跳过关卡介绍 |
| `Esc` | 退出 |

## 运行

```bash
cd tankbattle
pip install pygame
python tank_battle.py
```

可选参数：

```bash
python tank_battle.py --level 5   # 从第 5 关开始
```

## 单元测试

```bash
python -m pytest test_game.py -v
```
